Dobble Game Editor

Введите ровно 31, 43 или 57 слов/картинок (без повторов) — это нужно для настоящей Dobble-игры.
31 элемент — для 6 элементов на карточке
43 элемента — для 7 элементов на карточке
57 элементов — для 8 элементов на карточке
Важно: только такие варианты дают гарантию настоящей dobble-математики (ровно 1 совпадение в каждой паре).
